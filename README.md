# 本地 AI 无限画布原型

> PROTOTYPE — 用于验证节点式 AI 创作画布的交互与界面方向，不是生产版代码。

界面固定使用 A「专业导演台」。

## 启动

```powershell
cd C:\Work\codexx\AIVideo\local-ai-canvas-prototype
npm run dev
```

打开 <http://127.0.0.1:4173/>。

## 本批能力

- 无限画布的拖拽、缩放、平移和视图复位
- 文本、图片、视频和 AI 生成节点
- 点击图片节点的预览区复制图片资源，点击“导入/替换图片素材”按钮选择本机图片
- 导入图片会自动生成适合画布的 WebP 预览，并随画布保存在浏览器本地
- 图片导入后，图片节点会默认使用资源文件名命名
- 视频节点的提示词可用 `@` 引用直接连入的图片节点，按连线建立顺序显示为 `@图片1`、`@图片2`……
- 原 AI 生成器与视频节点统一为“视频生成”节点，旧画布在读取或导入时会自动迁移
- 视频生成默认使用 `Seedance 2.0 Mini`，支持 `3:4`、`4:3`、`9:16`、`16:9`、`1:1`、`21:9` 比例及 4–10 秒时长
- 视频节点保持固定高度，长提示词只在画布节点中截断预览，属性编辑区仍保留完整内容
- 画布中的视频节点只显示提示词摘要，不显示操作按钮；复制提示词按钮保留在右侧属性编辑区
- 连线支持两种方式：先后点击输出端口和目标节点，或从输出端口拖拽到目标节点后松开
- 界面固定为 A「专业导演台」，不再提供方案切换；没有选中节点时右侧属性检查器整体隐藏
- 节点右侧、底部和右下角可拖拽调整宽度、高度或整体尺寸；尺寸会保存，连线端点随节点边缘同步移动
- 顶部项目选择器支持创建和切换多个独立项目；项目名称、节点、连线和画布视图分别保存，旧版单项目数据会自动迁移
- 点击“复制提示词”复制格式为 `生成视频：提示词内容，16：9，8s`，提示词内部保留原有换行；不复制连接图片
- 图片节点的图片区域用于复制该图片资源；“导入/替换图片素材”按钮用于选择本机文件
- 图片节点的预览高度会跟随原始宽高比（最高 360px），完整显示资源内容而不裁切图片边缘
- 连线端点在任意画布缩放比例下都保持易点击的屏幕尺寸，并带有扩展命中热区
- 连线具有加宽的鼠标命中区；悬停时连线变红并提示删除，点击即取消连接，且可撤销
- 右键节点可复制、粘贴或删除；右键画布可撤销、重做或在鼠标位置粘贴
- 画布快捷键：`Ctrl/Cmd+C` 复制、`Ctrl/Cmd+V` 粘贴、`Ctrl/Cmd+Z` 撤销、`Ctrl/Cmd+Shift+Z` 或 `Ctrl+Y` 重做、`Delete` 删除
- 节点选择、删除、连线和参数编辑
- 本地自动保存
- JSON 导入与导出

AI 模型调用、真实视频生成、用户账号与云端协作不在本批范围内。
